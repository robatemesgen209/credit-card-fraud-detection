# Dataset statement

This project uses the uploaded `creditcard(1).csv`, the ULB/Kaggle Credit Card Fraud Detection benchmark referenced by the Module 5 group report. The raw file has 284,807 rows and 31 columns. It contains 1,081 exact duplicate rows and no missing values. Following the Module 5 report, exact duplicates are removed before splitting, leaving 283,726 rows and 473 fraud cases (0.1667%).

The 30 model inputs are `Time`, `Amount`, and `V1`–`V28`; `Class` is the binary target (0 legitimate, 1 fraud). The dataset is historical and covers two days in September 2013. It is not representative evidence of current bank fraud performance. Confirm the original source's terms before redistribution. No synthetic records are generated by this project.
